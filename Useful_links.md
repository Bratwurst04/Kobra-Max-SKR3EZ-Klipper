# Useful links

This page collects external projects, guides and discussions used while researching the Anycubic Kobra Max conversion.

> [!NOTE]
> These links were used as references, clues or comparison material.
> They do not necessarily match this exact hardware revision or final wiring. The verified information for this build is documented in [Wiring.md](./docs/Wiring.md) and the cfg files in [`docs/config`](./docs/config/).
